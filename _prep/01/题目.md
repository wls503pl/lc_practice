计算每个函数的独占运行时间
有一颗 CPU，同一时间只能运行一个函数。函数运行过程中可能被其他函数打断：被打断的函数会暂停，等打断它的函数结束后，再从暂停处继续运行。
一共有 n 个函数，编号为 0 到 n - 1。给你这些函数的执行日志 logs，请计算每个函数实际占用 CPU 的总时间。
每条日志的格式是：
text
函数编号:start:时间戳
或
text
函数编号:end:时间戳
其中：
start 表示这个函数从该时间戳对应的秒开始运行。
end 表示这个函数在该时间戳对应的秒运行完毕。
开始和结束的时间戳都要计入运行时间。
函数被打断、暂停期间，不计入它的运行时间。
如果同一个函数运行了多个时间段，就把这些时间段的运行时间相加。
请返回一个长度为 n 的数组。数组中第 i 个元素表示编号为 i 的函数总共运行了多少秒。
示例
text
n = 3

logs = [
  "0:start:0",
  "2:start:4",
  "2:end:5",
  "1:start:7",
  "1:end:10",
  "0:end:11"
]
运行情况：
函数 0 在第 0 到第 3 秒运行，之后被函数 2 打断；函数 2 结束后，函数 0 在第 6 秒恢复运行，并在第 11 秒结束。
函数 2 在第 4、5 秒运行。
函数 1 在第 7 到第 10 秒运行。
因此返回：
text
[6, 4, 2]
